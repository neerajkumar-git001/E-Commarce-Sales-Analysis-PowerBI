## Project Overview

The **E-Commerce Sales Analysis Dashboard** is an interactive Business
Intelligence project developed using Microsoft Power BI.

The purpose of this project is to analyze e-commerce business performance
through sales, profit, orders, quantity, product categories, customer
segments, and regional analysis.

The dashboard transforms raw transactional data into meaningful business
insights that help stakeholders monitor performance, identify growth
opportunities, and support data-driven decision-making.

## Business Problem

E-commerce companies generate large amounts of transactional data.
However, raw data does not provide a clear and consolidated view of
business performance.

Business stakeholders need answers to important questions:

- How much revenue is being generated?
- Is sales performance improving over time?
- How does current performance compare with the previous year?
- Which product categories generate the highest sales?
- Which products contribute the most profit?
- Which regions perform well?
- Which customer segments contribute to business performance?
- Are profit margins improving?
- Which areas require further investigation?
- Where are potential growth opportunities?

This project addresses these requirements through an interactive
business-focused dashboard.

## Key Performance Indicators

| KPI | Business Purpose |
|---|---|
| Total Sales | Measures total revenue generated |
| YTD Sales | Measures sales performance during the current year |
| YOY Sales Growth | Compares sales performance with the previous year |
| Total Profit | Measures total profit generated |
| YTD Profit | Measures current-year profit performance |
| YOY Profit Growth | Compares profit performance with the previous year |
| Profit Margin | Measures profitability relative to sales |
| Total Orders | Measures the number of unique orders |
| YTD Orders | Measures current-year order performance |
| Total Quantity | Measures the total quantity sold |
| YTD Quantity | Measures current-year quantity performance |
